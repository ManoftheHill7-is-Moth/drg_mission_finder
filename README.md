# drg\_mission\_finder

Prints any matching mission that will appear on the mission scanner in Deep Rock Galactic to a text file using the biome type, primary objective, secondary objective, warnings, mutators, cave complexity, cave length, or season.

Big thanks to rolfosian for creating https://doublexp.net/, the website that this finder pulls its daily data from.

Extract 'data/drg\_missions\_2026-2029.7z' for up-to-date missions to search through.



Recommendations for maximizing xp chances and finding a "white whale" (50k+ xp):

* Season 6 (ossium gems are worth 420 xp each, so finding the max of 7 is ideal)
* Haz 5+ (2 2 2 2)
* Azure Weald or Fungus Bogs (croppa spawns more frequently)
* Mining Expedition 400 Morkite (provides 1 xp per morkite deposited after the primary quota is completed)
* Not hollomite or dystrum as they are always worth less than other secondaries. Glyphid eggs spawn swarmers worth 1 xp each whereas each gunk seed is worth 3 xp (any other mineral secondary only grants 3 xp for depositing above quota)
* Max Cave and Complexity (3)
* Double XP and Core Corruption (guaranteed core stone worth 1000 xp)
* Pots o' Gold grants x4 gold mined (Dark Morkite only grants x1.44 morkite mined)
* Yuletide Event (error cubes are worth 4000 xp and have a 1:26 chance of spawning by breaking open presents)
* A lot of luck!



Change the code to customize the mission finder to your liking and feel free to help improve it here. Rock and Stone!
